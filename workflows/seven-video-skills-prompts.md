# 七个视频制作工具：来源与可复制提示词

这些是公开工具的调用起点。不同版本的风格数量、运行环境和声音接入会变化，以各仓库当前说明为准。下列提示词是工作流建议，不是各作者的原始提示词，也不保证一次生成成功。

## 1. video-shotcraft

[原始仓库](https://github.com/Vincentwei1021/video-shotcraft)

```text
请用video-shotcraft把我的网页做成宣传片。先读取真实页面，整理可用页面与实际交互；推荐镜头配方，给出短预览后按我选定的方向制作。保留网页文字的可读性，交付可编辑工程、成片和素材来源。
```

## 2. xilo-opus-video

[原始仓库](https://github.com/Kianzzz/xilo-opus-video)

```text
请用xilo-opus-video处理我提供的想法、文章或参考片。先提出三套画风和讲法有明显区别的方案，每套给一张关键帧或短预览；我选定后再做完整成片。不要只换颜色，不要擅自改变已定稿的旁白。
```

## 3. lemo-opuscar

[原始仓库](https://github.com/lemomo-ai/lemo-opuscar)

```text
请先读取lemo-opuscar风格库，用中国水墨风格表现我提供的内容。保留纸张、墨色浓淡、逐笔显影及笔触扩散；先展示一镜，确认后制作。提供完整作品、可编辑源文件及使用的风格说明。
```

## 4. mg-styles-15

[原始仓库](https://github.com/Vincentwei1021/mg-styles-15)

```text
请从mg-styles-15读取我指定风格的原始提示词和源码。保留Signature features，按我的内容改写Creative seed，制作片头、转场或产品动画。先验证动作前中后，再交付成片、配乐来源和可编辑源码。
```

## 5. huashu-art-motion

[原始仓库](https://github.com/alchaincyf/huashu-art-motion)

```text
请用huashu-art-motion给我的讲解配动画。先写句意、动作与结果对应的镜头表，按内容选择艺术风格或解说语法；用实际物体的变化表达，不要把全片做成静态字卡。用现有录音锁定时间，交付MP4、镜头表和工程。
```

## 6. dashi-animationstyle

[原始仓库](https://github.com/chuspeeism/dashi-animationstyle)

```text
请用dashi-animationstyle处理我的中文口播，沿用我提供的录音。按口播语义设计画面，并让关键字出现时间对齐实际发音；先给代表镜头，再完成横版1080p成片和字幕。先检查当前系统的字体与导出兼容性。
```

## 7. wtt-code-animation-studio

[原始仓库](https://github.com/WaterDJiang/Wattter_openSkills/tree/main/wattter_skills/wtt-code-animation-studio)

```text
请先读取wtt-code-animation-studio的许可与制作流程。以我的故事开发剧本，给出画风建议供我选择，再拆分镜、准备素材、对齐配音并制作有声成片。交付中文剧本、分镜、素材索引、源码和MP4。
```
