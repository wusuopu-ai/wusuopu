# 大神自媒体 Skill

把选题、口播文案、剪辑脚本、本人声音克隆、数字人、字幕与后期剪辑串起来的一套 AI 视频制作技能。支持第一次使用，也支持接着已有工程继续制作。

**[下载完整技能包 v2.0](https://github.com/15263076909/wusuopu/raw/refs/heads/main/大神自媒体技能包_v2.0.zip)**

## 能做什么

- 选题、事实核查、可复制口播文案与剪辑镜头表。
- 创建或复用本人声音，生成配音并核对读音与内容。
- 创建或复用数字人，用定稿配音生成口播视频。
- 真人口播精剪、证据素材与动画包装、同步字幕、封面及 MP4 导出。
- 记录工程状态、恢复未完成任务，并按声音、字幕、画面分别验收。

可以只使用其中一步。真人原片不需要克隆声音或创建数字人。

## 第一次安装

1. 下载 ZIP 并解压到自己的电脑。
2. 将解压后的文件夹位置告诉 Codex，复制下面这句话：

```text
请安装这个文件夹里的 dashen-zimeiti 技能：先检查 SKILL.md 和文件内容，再将 dashen-zimeiti 文件夹安装到我的 Codex 用户技能目录。如果已经安装同名技能，先备份，再合并更新，不覆盖我的个人配置。安装后检查技能是否能被识别，并告诉我哪些视频制作工具可用、哪些还需要配置。不要上传我的素材或生成收费内容。
```

3. 安装后开始使用：

```text
使用 $dashen-zimeiti。我第一次使用，想做一条面向【你的观众】的视频，主题是【你的主题】。请先检查工具，再用简单的话带我完成。我不懂的设置请解释用途，不要假定我已经有声音模型或数字人。
```

首次没有识别到技能，可新开聊天或重启客户端后再试。ZIP 中的「先看这里.md」有数字人口播、真人剪辑和只写文案的更多使用示例。

## 声音与数字人

默认参考路线：Fish Audio 配音 → HeyGen 数字人 → 可用剪辑工具或 HyperFrames/Remotion 工程后期。

技能会先检查当前账号和工具，然后引导准备本人录音、照片或平台要求的视频；第一次先做声音和口型短样，再生成整条。本人验证需要本人完成。已有声音或形象会优先复用。

这套技能提供工作方法，不附带服务账号、生成额度、剪辑软件、作者的声音或形象。工具支持、服务费用和使用权限以当前账户为准。不会自动发布视频或购买套餐。
