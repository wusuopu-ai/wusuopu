## v2.1 更新

- 标准化制作方法：句意镜头表、人物与前景叠层、真实素材/证据、手绘解释动画、动效、精剪与字幕、独立4:3和3:4封面、导出验收。
- 行业研究：使用实际工具采集可见作品与评论，保留出处、日期和读取范围；不把点赞当播放量。
- 自动整理与报告：去重来源库、分平台/账号/指标统计、评论问题、账号与结构报告、带理由和证据计划的候选选题、选定后的原创初稿。
- 新一期骨架与空白研究配置；更新保留用户自己的配置、声音、形象和工程。

采集和语义分析由 AI 助手执行；Python 标准库脚本负责校验、统计和文件输出，不自行登录平台或调用付费模型。完整结构需要实际读到视频或转写。

## 安装

下载ZIP解压，将文件夹位置告诉Codex，复制：

```text
请检查并安装这个文件夹里的 dashen-zimeiti 技能。已有同名技能先备份、合并更新，保留我的本机偏好和个人配置。安装后检查识别情况及可用工具，再带我完成本次需要的基础配置。不要上传素材或生成收费内容。
```

首次使用、研究、数字人口播和真人剪辑的指令见 [先看这里](先看这里.md)。技能入口在ZIP内的 `dashen-zimeiti/SKILL.md`；不同客户端工具适配单独核查。
